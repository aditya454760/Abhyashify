# Prepkram

(Prepkram was called Abhyashify until October 2026. The repository and the site address still use the old name until the GitHub repository is renamed. When that happens, change `BASE` and `REPO` at the top of `app/seo.py`, the `matches` line in `extension/manifest.json`, and rebuild.)

Prepkram is a study planner for competitive exams. You pick your exam, it builds a day-by-day timetable up to your exam date, rings an alarm when a block is due, asks you to log what you actually did, and at the end of the week shows how the week went compared to the plan. I built it for my own GATE DA 2027 preparation, and it now works for any exam on the list below.

You can try it here: **https://aditya454760.github.io/Abhyashify/**

## What it does

- **Look.** The interface is a two-ink print: paper ground, press-blue ink for text and rules, a second ink (pink unless you pick another accent) and a yellow highlighter for what is current. Panels are flat tinted fields, the day is a ruled timetable with a bubble at the end of each block (empty, half, filled, or crossed), study time is counted in answer-sheet bubbles, and choices in the setup are filled in like an answer sheet. Fonts (Archivo, Atkinson Hyperlegible Next and Noto Sans Devanagari) are served from `docs/fonts`, so it looks the same offline. The styling is `app/src/riso.css` on top of the tokens in `head.html`. Text is at least about 7:1 on the paper (the accent used as text is about 5:1), targets are 44px, and light and dark both exist.
- **Course setup.** On first launch (and from Settings, or by telling the assistant "set up my course") a short guide walks through: exam, then paper or branch (GATE CS, DA, ECE, EE, ME, CE and more; JEE Main, Advanced, B.Arch, B.Planning; NEET UG/PG; UPSC; SSC; NDA; CDS; CAT and other MBA tests; CLAT; CA; bank; railway; CUET; NET/JAM; TET; boards; state PSC), with an "Other" option everywhere for your own exam and subjects. Each paper comes with its subjects. If a paper has optional subjects, you choose yours. It then confirms your exam date (or month/year, or your own target date), asks about your hours, which parts of the day suit you, days off and the weekly mock test, and generates a timetable from today to that date in three phases (learn, revise, final mocks). You can follow it as it is or edit any block. Exam dates shown are only typical timings, always check the official notice.
- **Permissions in one go.** Right after the course is chosen it asks once for notifications, saved storage, the microphone and study-tool tracking, so the features work without hunting through settings.
- **Study tools.** Add the apps, websites and YouTube channels you study with. Opening one from the Today screen starts a timer and the time until you return is logged automatically, with no further questions after the one-time consent. On a laptop, the browser extension in `extension/` counts time on the study sites you choose and sends it to the app by itself. Time in apps you open yourself on a phone comes from the Android companion's JSON file (import it under Plan, Study tools and permissions).
- Builds a day-by-day schedule from my subjects and the exam date, and keeps a revision buffer at the end.
- Rings an alarm shortly before each block (while the page is open).
- Lets me log a session by hand or run a timer, and gives me a weekly report.
- Tracks study material (books, lecture playlists, problem sets) and how much of each I've finished.
- Has a built-in assistant (the chat button at the bottom right). I can type or talk to it. It answers questions about how the app works, sets alarms and reminders, schedules tests and mock tests and records my scores, builds a new weekly schedule, adds subjects and study material, starts the timer, and changes the theme, accent colour and background. Everything it changes can be undone with one tap. It can talk back in a female or male voice.
- Works in English and Hindi. The language switch is in Settings (and on the sign-in screen). It changes the whole app, the assistant's replies and the voice chat. The assistant is called **Anu** with the female voice and **Adi** with the male voice, and it understands Hindi (देवनागरी) and Hinglish commands as well as English.
- Can speak in a voice you choose for Adi and Anu, with the speaker's permission: an online cloned voice (your own ElevenLabs key), sentences saved so they also play offline, and a trained offline voice pack that runs inside the app. The `voice-kit/` folder has the recorder, the training notebook and the steps.
- Syncs through Google sign-in, so the phone, tablet and laptop all show the same data. If I study on my phone and my laptop at the same time for the same course, that overlap is counted once, not twice.

## Search, answer engines and AI assistants (SEO, AEO, GEO)

The app itself is a JavaScript page behind sign-in, which gives a crawler very little to read. So the site also has plain HTML pages, all generated by `app/seo.py` when you run `python3 app/build.py` (it reads the same exam catalogue the app uses, so the pages can't drift from it):

- `about/` and `hi/about/`: what it is, the setup steps and ten short question-and-answer entries (`FAQPage` and `HowTo` structured data). Answers start with the answer, so a search snippet or an AI answer can quote them.
- `guides/timetable/` and `guides/hours/` (English and Hindi): how to make an exam timetable in seven steps with the month-by-month split the app really uses, and the starting study hours and mock length per exam. They target the searches students actually make (study plan, timetable, how many hours).
- `exams/` and one page for each of the 17 exam families (`exams/gate/`, `exams/jee/` and so on), each in English and Hindi, with the preloaded papers, subjects, usual months, study hours and mock length. Every page says these are general-knowledge hints, not official dates.
- On `index.html`: title, description, canonical, Open Graph and Twitter tags with a 1200x630 share image (`docs/og.png`, drawn from `app/og.html` by `app/og.py`), `WebSite` and `WebApplication` JSON-LD, and a `<noscript>` summary with links.
- `sitemap.xml` (English and Hindi pairs linked with `hreflang`), `robots.txt` (allows search and AI crawlers), `llms.txt` and `llms-full.txt` (a plain-text guide for AI tools), and a `404.html`.
- Links to the About and exam pages appear on the first-run screen and in Settings so crawlers and people can find them.

`app/test/seo.test.py` checks every generated page: title and description lengths, canonical, Open Graph, JSON-LD parses, one `h1`, `hreflang` pairs point at each other, every internal link and sitemap entry exists.

What this can't promise, and what is left for you:

- Nobody can guarantee a ranking or that an AI assistant will quote the site. These changes make it findable and quotable; they don't make it rank.
- I couldn't reach the live site from where I build it, so I haven't seen Google or Bing fetch it. After the push, open the live URLs and submit `https://aditya454760.github.io/Abhyashify/sitemap.xml` in Google Search Console and Bing Webmaster Tools (add the site as a "URL prefix" property).
- Search engines read `robots.txt` only at the root of a host. This site lives under `/Abhyashify/`, so `docs/robots.txt` is ignored on `github.io` (everything is crawlable by default anyway, so nothing is blocked). It starts to count if you move to your own domain. If you do, change `BASE` at the top of `app/seo.py` and rebuild.
- The pages are only as accurate as the catalogue. Subjects and months were written from general knowledge.

## Installing it like a normal app

Open the link above in Chrome or Edge. On a computer there's an install icon in the address bar. On Android, open the browser menu and tap **Install app** (or use the Install button inside Prepkram's Account sheet). On iPhone, open it in Safari, tap Share, then **Add to Home Screen**. After that it opens in its own window, has its own icon, and still loads when you're offline. Your data catches up once you're back online.

## The assistant

It works out of the box with no account and no cost. Without a key it uses a built-in understanding of everyday requests ("remind me to revise ML at 8 pm", "schedule a mock test on Sunday at 10", "make accent teal and background aurora", "how do I log a session?"). For free-form requests there is an optional Smart mode: in the assistant's settings I paste my own Gemini (free) or Anthropic key, and the assistant then uses that model to understand me. The model can only ask the app to do things from a fixed list, and the app checks each one. It can't delete courses or data, and replacing the whole schedule needs a yes first.

Things worth knowing:

- Custom voices: read `voice-kit/README.md`. Only use a voice whose owner agreed. The cloned voice sends the recordings to ElevenLabs and needs a paid plan there. The offline voice pack needs training (a free Colab GPU is enough). Adding the offline engine adds about 33 MB of files to the site. They download only when someone adds a voice pack, and are then saved for offline use.

- Language: switch in Settings, in the assistant's settings, or just say "हिन्दी में बोलो" or "switch to English". Hindi text, speech recognition and speech output all follow it. The Hindi in the app comes from a built-in dictionary plus the assistant's own Hindi answers. It is good for everyday use, but a few odd phrasings may still show in English, and your own names (subjects, books, test titles) are never translated. The Android usage-tracker app is not translated. The CSV export keeps English column headings so Google Calendar can read it.
- Hindi voices depend on the device. Chrome on Android usually has one; many laptops don't, and then the assistant can't speak Hindi aloud even though the text works. Smart mode (your own key) understands free-form Hindi better than the built-in understanding does.
- Alarms and reminders ring only while the page is open and the bell is on. A web page can't wake a closed phone. The Android wrapper (on the to-do list) is how that gets fixed.
- Tracking limits: a web page cannot see what other apps or tabs you use. What it can do is note when you leave to a study tool from Prepkram and when you come back. Time in anything you open some other way comes only from the Android companion's file. The browser extension covers desktop browser tabs only (not desktop apps). I have not tested any of this on a real phone, and the Android companion itself was not changed for this release.
- Exam catalogue: subjects and typical timings were written from general knowledge, not downloaded from official sites. Check the syllabus and date on the exam body's own website, and edit the subjects if they differ.
- A mock test is scheduled, timed with the study timer, and its score is saved and shown in the Report tab. There's no built-in question bank. In Smart mode I can ask it to quiz me in the chat.
- Voice needs a browser with speech support (Chrome, Edge and Safari have it). Listening needs the internet and microphone permission, and Chrome sends the audio to Google to turn it into text. The male and female voices are the ones installed on the device. If the device has only one kind, the assistant shifts the pitch.
- My key is stored only on this device and is sent only to the provider I chose. In Smart mode my messages and a short summary of my schedule go to that provider.

## What's tested and what isn't

I'd rather say this up front than have you find out later.

- The merging of overlapping study time has its own tests, and they pass.
- The generated search pages have 2,181 checks (`python3 app/test/seo.test.py`). A real-Chromium run confirmed the fonts load, the structured data parses and the offline app is not replaced by an About page.
- The browser extension has 16 tests in real Chromium. The course setup has 118 tests for the catalogue, steps and generated timetable, plus 78 for the generator on 300 random settings, short horizons, tool tracking, the phone-usage import, cloud-rule limits and creating a new course while signed in. The assistant passes 51 tests, and 33 more cover Hindi: switching the whole app and back, the names Adi and Anu, Hindi and Hinglish commands, Hindi replies, and the Hindi voice settings. A scan of the app in Hindi finds no English left over except names and brands. The custom voices have 30 tests for the online voice (against a stand-in for ElevenLabs), 13 browser tests for the offline voice engine (real Chromium, a stand-in model that echoes the phoneme ids it receives, including after going offline and reloading) and 17 for the recorder. What isn't tested: how a real trained voice sounds, the real ElevenLabs service, the training notebook (it needs a GPU), and any of it on a real phone. The Hindi was written by an AI, so someone fluent should still read through the app and fix any phrase that sounds wrong. (The English tests cover understanding of requests, actions, undo, the chat window, colours, reminders ringing, and Smart mode against a stand-in network.) The real microphone, real voices and real calls to Gemini or Anthropic haven't been tried yet, so those need a hand test.
- The website's sync code passes 22 tests against a stand-in for Firestore, using two simulated devices. That is not the same as the real thing, so the real Google sign-in and real database still need to be tried by hand.
- The Firestore security rules have tests (`npm run test:rules` inside `sync/`), but I haven't been able to run them yet. They need Node and Java and the Firebase emulator.
- The Android project builds in Android Studio. I haven't run it on a phone yet.

## The Android usage tracker

A web page can't see what other apps you use, so this small Android app does that part. It reads the Usage Access data on the phone, adds up how long each study app was open on each of the last 7 days, and gives the result as JSON.

To run it:

1. In Android Studio choose Open and pick the `android` folder. Wait for the Gradle sync.
2. Plug in your phone with USB debugging on, or start an emulator, and press Run.
3. Tap **Open usage access settings**, pick *Prepkram Usage* and switch it on. Then come back to the app.
4. Tap **Choose study apps** and tick the apps you study with. Leave out anything you also use for fun, because a chosen app counts fully as study time.
5. The app shows time per day and per app. **Share** or **Copy** gives you the JSON.

The JSON looks like this:

```json
{
  "source": "abhyashify-usage",
  "generated": "2026-10-05T14:30:00Z",
  "days": [
    {
      "date": "2026-10-05",
      "study_minutes": 135,
      "apps": [
        { "package": "com.example.reader", "label": "PDF Reader", "minutes": 95 },
        { "package": "com.example.notes", "label": "Notes", "minutes": 40 }
      ]
    }
  ]
}
```

### How the usage time is counted

- An app counts as open from the first screen you see until the last one pauses.
- Turning the screen off or shutting the phone down ends any open session.
- A session that runs past midnight is split between the two days, using the phone's time zone.
- Only the apps you picked count. The app can't tell what you did inside them, so a YouTube lecture and a YouTube Short look the same to it.
